# Predictive Modeling Case Study: Product Revenue Analysis

This project analyzes online sports product revenue using Nike and Adidas product data.

## Objectives

- Explore revenue differences across listing price quartiles
- Examine the relationship between description length and product ratings
- Build predictive models for revenue
- Identify products with risk of low revenue

## Models Used

- Linear Regression
- Regression Tree
- Neural Network
- Logistic Regression
- Classification Tree
- Neural Network Classifier
